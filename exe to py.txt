Инструкция по сборке проекта MultiTap в один exe (Windows)

Вариант 1: PyInstaller (рекомендуется)
1) Установить зависимости:
   pip install -r requirements.txt
   pip install pyinstaller

2) Запуск сборки:
   - Однофайловый exe:
     pyinstaller --noconfirm --onefile --name MultiTap --add-data "app;app" --hidden-import PyQt5.sip -w app/__main__.py

   Пояснения:
   - --onefile: один exe-файл
   - --name MultiTap: имя exe
   - --add-data "app;app": включает директорию app внутрь пакета; формат "ВХОД;ВЫХОД" для Windows
   - -w: без консольного окна
   - --hidden-import PyQt5.sip: иногда требуется для корректной упаковки PyQt5

3) Выходной exe появится в папке dist/MultiTap.exe

4) Файл настроек Setting.ini будет лежать в рабочей директории (там же, где запускается exe). Можно указать иной путь при необходимости.

Вариант 2: Nuitka (более оптимизированная сборка)
1) Установить зависимости:
   pip install -r requirements.txt
   pip install nuitka ordered-set zstandard

2) Запуск сборки (пример):
   python -m nuitka --onefile --windows-disable-console --enable-plugin=pyqt5 --include-data-dir=app=app --output-filename=MultiTap.exe app/__main__.py

Подсказки и проблемы
- Требуются права администратора для глобального перехвата клавиатуры (библиотека keyboard).
- Для автозапуска в Windows приложение должно иметь доступ к HKCU/Run (это делает сама программа).
- Если exe не видит COM-порты, убедитесь что установлены драйверы для Arduino/ESP32.
- Если PyQt5 не запускается, попробуйте добавить дополнительные hidden-import:
  --hidden-import PyQt5.QtCore --hidden-import PyQt5.QtGui --hidden-import PyQt5.QtWidgets
- Для корректной работы глобальной клавиатуры может потребоваться запуск от имени администратора.
